# 🎀 Estudos de Git & GitHub

୨୧ ─────────────── ୨୧

Repositório criado para praticar e desenvolver conhecimentos em **Git e GitHub**, ferramentas essenciais para o controle de versão e a colaboração em projetos de desenvolvimento de software.

## 🌸 Sobre o projeto

Este repositório reúne comandos, exercícios e experimentos realizados durante meus estudos de controle de versão.

O objetivo é compreender na prática como organizar projetos, acompanhar alterações, trabalhar com branches e colaborar utilizando o GitHub.

**Status:** 🌷 Em andamento

## 📚 Conteúdos praticados

### ୨୧ Fundamentos do Git
- [x] Inicialização de repositórios (`git init`)
- [x] Verificação de alterações (`git status`)
- [x] Adição de arquivos (`git add`)
- [x] Criação de commits (`git commit`)
- [x] Visualização do histórico (`git log`)
- [x] Comparação de alterações (`git diff`)

### ୨୧ Branches e integração
- [x] Criação de branches (`git branch`)
- [x] Alternância entre branches (`git switch`)
- [x] Integração de branches (`git merge`)
- [x] Resolução de conflitos
- [x] Exclusão de branches

### ୨୧ GitHub e repositórios remotos
- [x] Conexão com repositórios remotos (`git remote`)
- [x] Envio de alterações (`git push`)
- [x] Atualização do repositório local (`git pull`)
- [x] Criação de Pull Requests
- [x] Revisão e merge de Pull Requests

### ୨୧ Organização e boas práticas
- [x] Criação e configuração do `.gitignore`
- [ ] Clonagem de repositórios (`git clone`)
- [ ] Fork de repositórios
- [ ] Fluxo de colaboração em equipe
- [ ] Boas práticas de versionamento
