## 📚 01. Conteúdos estudados

### 🌷 Fundamentos do Git
- Inicialização de repositórios (`git init`)
- Verificação de alterações (`git status`)
- Adição de arquivos (`git add`)
- Criação de commits (`git commit`)
- Visualização do histórico (`git log`)
- Comparação de alterações (`git diff`)

### 🌸 Branches e integração
- Criação e gerenciamento de branches (`git branch`)
- Alternância entre branches (`git switch`)
- Integração de branches (`git merge`)
- Resolução de conflitos
- Armazenamento temporário de alterações (`git stash`)
- Rebase (`git rebase`)
- Cherry-pick (`git cherry-pick`)

### 🩷 Histórico e recuperação de versões
- Criação de tags e versionamento (`git tag`)
- Desfazimento de alterações com Reset (`git reset`)
- Reversão de commits com Revert (`git revert`)
- Recuperação de referências com Reflog (`git reflog`)

### ☁️ GitHub e colaboração
- Conexão com repositórios remotos (`git remote`)
- Envio e atualização de alterações (`git push` e `git pull`)
- Sincronização entre branches locais e remotas
- GitHub Flow
- Pull Requests e Code Review
- Comentários, sugestões e aprovações
- Integração de alterações por meio de merge

### 🔐 Proteção e automação
- Branch Rulesets e regras de proteção
- Regras de aprovação de Pull Requests
- Histórico linear
- Verificações automatizadas (Status Checks)
- GitHub Actions
- Integração Contínua (CI/CD)
- Testes automatizados com Python e pytest

## 🧪 02. Práticas realizadas

Durante os estudos, também desenvolvi exercícios para aplicar os conceitos na prática:

- Criação e gerenciamento de repositórios locais e remotos.
- Simulação de branches, merges e resolução de conflitos.
- Prática com Stash, Rebase, Cherry-pick, Reset, Revert e Reflog.
- Criação e revisão de Pull Requests.
- Configuração de regras para proteger a branch `main`.

- Criação de testes automatizados com pytest.

- Integração dos testes automatizados às regras de proteção da branch.
