୨୧ ─────────────── ୨୧

Repositório criado para praticar e desenvolver conhecimentos em **Git e GitHub**, ferramentas essenciais para o controle de versão e a colaboração em projetos de desenvolvimento de software.

## 🌸 Sobre o projeto

Este repositório reúne anotações, comandos, exercícios e experimentos realizados durante meus estudos de controle de versão.

O objetivo é compreender na prática como acompanhar alterações, organizar projetos, gerenciar branches, recuperar versões anteriores e trabalhar com repositórios remotos.

**Status:** 🌷 Em andamento

## 📚 Conteúdos estudados

### ୨୧ Fundamentos do Git
- Inicialização de repositórios (`git init`)
- Verificação de alterações (`git status`)
- Adição de arquivos (`git add`)
- Criação de commits (`git commit`)
- Visualização do histórico (`git log`)
- Comparação de alterações (`git diff`)

### ୨୧ Branches e integração
- Criação e gerenciamento de branches (`git branch`)
- Alternância entre branches (`git switch`)
- Integração de branches (`git merge`)
- Resolução de conflitos
- Exclusão de branches
- Rebase (`git rebase`)
- Cherry-pick (`git cherry-pick`)

### ୨୧ Manipulação e recuperação de versões
- Armazenamento temporário de alterações (`git stash`)
- Criação de tags e versionamento (`git tag`)
- Desfazimento de alterações com Reset (`git reset`)
- Reversão de commits com Revert (`git revert`)
- Recuperação de referências com Reflog (`git reflog`)

### ୨୧ GitHub e repositórios remotos
- Conexão com repositórios remotos (`git remote`)
- Envio de alterações (`git push`)
- Atualização do repositório local (`git pull`)
- Sincronização entre branches locais e remotas
- Resolução de divergências entre repositórios
- Integração de alterações no repositório remoto
